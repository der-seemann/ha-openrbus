# Screed-drying entity projection

Screed drying is a global, default-off option (`screed_drying_enabled`). The
reviewed exact-address map runs before picker choices, entity setup, and poll
group assembly. Enabling it restores the normal catalog projections on reload.
Disabling it integration-disables existing registry rows while retaining
unique IDs; user-disabled entities stay user-disabled.

The complete address list, Core family/runtime-capability scope, source
evidence, and reviewed exclusions are in
[`global-register-filters.md`](global-register-filters.md). The filter does
not hide generic heating-program registers based on labels or proximity.
